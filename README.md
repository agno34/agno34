## Projects

### Unsupervised Analysis of MRI Brain Networks Using Subgraph Matching

**Master's Thesis** · C++ · Python · Bash

Structural analysis of brain connectomes using graph theory, subgraph matching, and dimensionality reduction techniques. The subgraph matching research code I contributed to is available in [**vbonnici/treeprox-subgi**](https://github.com/vbonnici/treeprox-subgi).

### Fake News Classification Using LSTM Networks

[**agno34/Sentiment_Analysis**](https://github.com/agno34/Sentiment_Analysis) · Python · Keras / TensorFlow

Deep learning model based on a Bidirectional LSTM network to distinguish real news from fake news, trained on the WELFake dataset (72,134 articles). Includes data preprocessing, model training with early stopping, and evaluation using accuracy, precision, recall, F1-score, and a confusion matrix. The project also includes a report covering the theoretical foundations of LSTM networks.

### Interpreter for a C-Like Programming Language

[**pezwastaken/lang-interpreter**](https://github.com/pezwastaken/lang-interpreter) · C++

Interpreter for a small programming language with C-like syntax, supporting primitive types, user-defined structures, functions, control flow, and I/O. The architecture follows the **Visitor design pattern**, with separate analysis stages (IndexBinder and TypeChecker) and an interpretation phase involving **bytecode generation and execution**.

### Robot Motion Planning Using Constraint Programming

[**pezwastaken/constraints-moving-boxes**](https://github.com/pezwastaken/constraints-moving-boxes) · MiniZinc, C++, Python

University project in constraint programming: a MiniZinc model for planning the movements of a robot that moves boxes, featuring global constraints and an automated test suite.

### Gerrymandering Using Answer Set Programming

[**agnettiandrea/gerrymandering**](https://github.com/agnettiandrea/gerrymandering) · Clingo (ASP) · Python

Modeling the gerrymandering problem using Answer Set Programming, with multiple encoding variants, instance-generation scripts, benchmarks, and plots comparing solving times.
